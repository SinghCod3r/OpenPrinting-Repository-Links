Status Meaning

Status Meaning
🟢 Official OpenPrinting Repository is already under the OpenPrinting GitHub organization.
🟡 Contributor-owned Work is OpenPrinting-related, but the repository is still owned by the contributor or another account.
🔵 External upstream Work is maintained in another upstream project such as KDE, GNOME, Mozilla, LibreOffice, Zephyr, or COSMIC.
🟡 / 🟢 Work may exist both in a contributor repository and in the OpenPrinting organization.

Why Contributor-Owned Repositories Matter

Not every OpenPrinting-related project is moved into the official OpenPrinting/* organization.

A contributor may:

  • keep the original repository under their own GitHub account;
  • continue development in an upstream project such as KDE or GNOME;
  • contribute the result directly to another project;
  • create a prototype that remains useful even if it is not transferred;
  • finish a GSoC project and leave the repository in the contributor’s account.

Therefore, this directory should include both official OpenPrinting repositories and external/contributor-owned repositories.

How to Find More Missing Projects

Search for:

  1. GSoC project pages mentioning OpenPrinting.
  2. GitHub repositories created by OpenPrinting GSoC contributors.
  3. GitHub repositories linked from GSoC final reports.
  4. Pull requests made by OpenPrinting contributors in external projects.
  5. KDE, GNOME, Mozilla, LibreOffice, Zephyr and COSMIC printing work.
  6. Repositories mentioned in OpenPrinting mailing-list discussions.
  7. Projects that were prototypes but were never transferred to OpenPrinting/*.
  8. Old GSoC repositories that are still useful for future contributors.

Important Rule

Do not assume that a project is missing just because it is not inside OpenPrinting/*.

The goal of this directory is broader:

Find OpenPrinting-related work wherever it currently lives, and make it discoverable from one place.

Verification

Before adding a project as a confirmed entry, verify:

  • repository ownership;
  • contributor identity;
  • connection to OpenPrinting;
  • GSoC/project year;
  • mentor information;
  • current project status;
  • whether the work was upstreamed or transferred.

Unknown information should be marked as TBD instead of guessed.

Contribution

If you know an OpenPrinting-related repository that is missing from this directory, add it to the Master Project Directory and include the source or evidence for the entry.
