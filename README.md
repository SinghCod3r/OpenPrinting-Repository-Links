# 🌐 Why This Directory Is Needed

OpenPrinting development is not limited to repositories under the official GitHub organization.

A contributor may:

- create a repository during GSoC;
- continue development after GSoC;
- submit the work to KDE, GNOME, Mozilla, LibreOffice, Zephyr, or another project;
- keep the repository under their own GitHub account;
- create a prototype that is never transferred;
- contribute only part of the work upstream;
- maintain a project independently while still being part of the OpenPrinting ecosystem.

Because of this, searching only for:

```text
github.com/OpenPrinting/*
```

will not find all OpenPrinting-related work.

This directory provides a **single discovery point** for those projects.

# 🔍 How to Find Missing Projects

When adding new projects, search through:

### 1. GSoC

Look at:

- OpenPrinting GSoC project ideas
- accepted students
- final reports
- contributor GitHub accounts
- repositories linked from final reports

### 2. GitHub

Search for combinations such as:

```text
OpenPrinting
CUPS
CUPS 3
PAPPL
CPDB
printer application
printing
OpenPrinting GSoC
OpenPrinting contributor
```

Also search contributor accounts for repositories created during their GSoC period.

### 3. External Upstreams

Check printing-related contributions in:

- KDE
- GNOME
- Mozilla
- LibreOffice
- Zephyr
- COSMIC
- Gutenprint
- CUPS
- PAPPL
- Linux distributions

### 4. OpenPrinting Communication

Look through:

- OpenPrinting mailing lists
- GitHub issues
- GitHub pull requests
- project discussions
- GSoC reports
- mentor discussions

# ⚠️ Important: Do Not Assume Repository Ownership

A project should **not** be marked as an official OpenPrinting project only because:

- an OpenPrinting contributor created it;
- the project was part of GSoC;
- an OpenPrinting mentor supervised it;
- the project uses CUPS;
- the project was discussed by OpenPrinting.

The repository location and project relationship should be verified.

If something is uncertain, use:

```text
TBD
```

instead of guessing.
